## What Release 001 keeps and changes

Keeps:
- the code at `997831f` plus only the release files (Dockerfile targets, entrypoint Engine check, smoke test, compose);
- the same four ONNX models, with Engines rebuilt on the device at the batch each branch uses;
- the same settings: flags in `site.env`, secrets in `persistent/secrets/`;
- `steelcast.db`, copied into `persistent/database` before the first activation. The originals stay in `/home/ai/steelcast`, so the legacy units can come back.

Changes:
- both parsers are compiled in the image from source (DeepStream-Yolo vendored at the same commit);
- MediaMTX runs as a container (1.20.1, the image Mantri runs) with `mediamtx.yml` from `persistent/secrets/`; both native units are replaced (`replaces_units`);
- the image is read-only at run time, and nvinfer can no longer build an Engine from ONNX.
